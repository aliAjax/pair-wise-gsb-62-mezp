# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看、发布升版。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- JSON审阅包导出。

## 汛期值班离线交接

- **离线暂存**：切换到“巡检终端01（离线）”并断网后，现场复核、专业意见、处置方案先写入终端本地待办（Outbox），不改动内网正本；恢复网络后可逐条或全部重试合并。上报失败的待办继续留在终端，断网重试不丢失。
- **三方合并**：每条待办携带生成时的正本快照与版本号作为共同基线，回到内网后与值班台当前正本做三方比较。仅一边改动的字段安全并入；现场复核、专业意见按集合追加，互不覆盖。
- **签批保护**：晚到的“改方案”记录遇到值班台已签批方案时被拒绝覆盖，晚到版本保留为待交接分支，正本签批结论不变。
- **字段冲突交接**：同一异常两边都改了同一标量字段且取值不同时，两个版本都保留（异常 `branches` 留证并在 `conflicts` 列出字段、共同基线/值班台/晚到三方取值），值班负责人在“离线交接与合并”页或异常详情选择采用哪一侧，选择写入正本并留痕。
- **阈值版本**：阈值发布升版后，待现场复核/调查/待审批/应急联动等未结案异常按新版重算，作废旧签批并要求“按新版重新确认”后才能再次签批；已结案异常的阈值依据冻结，证据继续按结案时的原版查看。
- **版本依据一致**：异常列表“版本依据”列、异常详情依据条与导出的 JSON 审阅包都使用同一个 `resolveVersionBasis` 解析，已结案显示“结案冻结”，未结案显示现行阈值版本，三处口径完全一致。

演示路径：监测总览页发布阈值新版 → 异常处置页切到巡检终端断网暂存改动 → “离线交接与合并”页模拟值班台B并发修改同一异常 → 恢复网络重试合并 → 在字段冲突交接中心选择采用版本 → 审计追溯页导出审阅包。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
