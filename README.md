# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- 汛期离线巡检：复核与处置意见先留存终端本地待办，回到内网与值班台合并，恢复网络后继续重试上报。
- 两值班台同时修改同一异常：三向合并保留两边版本，逐字段列出冲突并交接；晚到记录不得覆盖值班台已签批方案。
- 阈值版本化：发布新版后未结案异常按新版重算并重新确认，已结案证据继续按原锁定版本查看。
- 列表、异常详情与导出审阅包统一显示同一阈值版本依据。
- JSON审阅包导出（含版本依据清单）。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
